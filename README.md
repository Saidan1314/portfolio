# Personal Portfolio

A personal portfolio website created to showcase my projects, interests, and
journey in Artificial Intelligence and technology.

## 🌐 Live Demo

**[adanarteaga.vercel.app](https://adanarteaga.vercel.app/)**

## 📖 About the Project

This website serves as a personal space to present my projects, experience,
interests, and other information in a clean and interactive interface.

The design and structure were developed iteratively, with a focus on
simplicity, visual presentation, responsiveness, and user experience.

## ✨ Features

- Responsive design for desktop and mobile
- Available in English and Spanish, switchable from the navigation bar
- Project showcase
- About section
- Tech stack and interests
- Photo gallery
- Interactive UI elements — a 3D scene that follows the cursor, orbiting
  technology logos, a typewriter heading
- Smooth animations and transitions
- Résumé download
- Contact and social links

## 🛠️ Built With

- **React** and **TypeScript**
- **Vite** as the build tool
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Spline** for the 3D scene
- Deployed on **Vercel**

## ⚙️ How It Works

The portfolio is organized into different sections that can be accessed
through the navigation menu.

Projects and personal information are presented through dedicated components,
while the interface adapts to different screen sizes to provide a consistent
experience across devices.

The language switch changes every piece of text on the page at once, and the
choice is remembered for the next visit.

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/Saidan1314/portfolio.git
```

Navigate to the project directory:

```bash
cd portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The project should then be available at the local development URL provided by
the development server.
